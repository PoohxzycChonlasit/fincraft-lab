# FinCraft Design-Taste Adapter

## Authority and loading order

Load this adapter only for authorized visual design, layout, styling, component
appearance, or page-composition work. Read, in order:

1. `AGENTS.md`.
2. `.agents/skills/fincraft-frontend-engineering/SKILL.md`.
3. Canonical visual and system contracts.
4. This adapter.
5. `.agents/vendor/taste-skill/design-taste-frontend-v1/SKILL.md`.

`TASTESKILL_ROLE: ADVISORY`

`CANONICAL_FINCRAFT_ROLE: AUTHORITATIVE`
`CONFLICT_RESULT: FINCRAFT_WINS`

## Use

Use the vendored guidance as a review aid for hierarchy, composition, spacing,
responsive quality, accessibility review, anti-repetition, restrained card and
pill use, visual intent before implementation, and self-review. It helps avoid
generic AI SaaS output; it does not define the FinCraft brand or authorize UI.

Use these local defaults:

```text
DESIGN_VARIANCE: CONTROLLED_MODERATE
MOTION_INTENSITY: MINIMAL_EVENT_DRIVEN_ONLY
VISUAL_DENSITY: MEDIUM_TOOL_REGIONS_RELAXED_LEARNING_REGIONS
DEPTH: INTERACTIVE_AND_SELECTED_ONLY
NORMAL_CONTENT: FLAT
GRAPH: SIMPLE_2D_LIST_SYNCHRONIZED
```

## Non-negotiable overrides

Never let TasteSkill change FinCraft colours, fonts, visual direction,
component anatomy, Mochi's role, Craft or Discovery Web structure, spoiler
protection, API contracts, TypeScript, or source-size limits. Do not install a
package, choose a framework, add external fonts/images/assets, permanent mocks,
fake metrics/testimonials/social proof, or unsupported business content.

GSAP, Framer Motion, Three.js, WebGL, 3D, particles, video backgrounds,
continuous animation, animated graph edges, and a dark-mode requirement are
prohibited. Preserve finite, reduced-motion-safe state feedback and the
synchronized semantic graph list.

## Required workflow

Follow: Observe, Explain, Component Map, File Plan, Refactor Check, Implement,
Verify, Teach Back, Checkpoint, Stop. This adapter adds no exception to package,
scope, accessibility, performance, or Product UI authorization rules.
